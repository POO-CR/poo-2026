# Clase 4: colaboracion entre objetos y miembros de clase (static)

Proyecto Java sin herramientas de construccion. Para abrirlo: en VSCode,
Archivo -> Abrir carpeta, y elegir esta carpeta (la que contiene src y lib).

- `src/Estudiante.java` y `src/Curso.java`: los archivos que hay que modificar.
- `src/GestionAcademica.java`: el programa que los usa. No se modifica, salvo
  para comentar la parte 1 y descomentar la parte 3 cuando el enunciado lo
  indique.

Para ejecutar, abrir GestionAcademica.java y usar el boton Run que aparece
sobre el metodo main. Los archivos compilados van a `bin/`, que no se entrega.

Las consignas estan en el enunciado de la actividad.
