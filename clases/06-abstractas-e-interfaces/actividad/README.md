# Clase 6: clases abstractas e interfaces

Proyecto Java sin herramientas de construccion. Para abrirlo: en VSCode,
Archivo -> Abrir carpeta, y elegir esta carpeta (la que contiene src y lib).

Es la jerarquia de la clase 5 ya terminada, con dos problemas que no se veian
hasta ahora.

- `src/Producto.java`: la superclase. Se modifica en la parte 2 (TODO 1 y 2).
- `src/Libro.java`, `src/Electronico.java` y `src/Alimento.java`: las tres
  subclases, completas y funcionando. Se modifican en las partes 2 y 3.
- `src/Suscripcion.java`: no hereda de nadie. Se modifica en la parte 3.
- `src/Descontable.java`: no existe todavia. Se escribe en la parte 3.
- `src/Tienda.java`: el programa que muestra el catalogo y, al final, liquida.

Para ejecutar, abrir Tienda.java y usar el boton Run que aparece sobre el
metodo main. Los archivos compilados van a `bin/`, que no se entrega.

Las consignas estan en el enunciado de la actividad.
