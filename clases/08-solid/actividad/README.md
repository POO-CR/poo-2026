# Clase 8: principios SOLID

Proyecto Java sin herramientas de construccion. Para abrirlo: en VSCode,
Archivo -> Abrir carpeta, y elegir esta carpeta (la que contiene src y lib).

- `src/Publicacion.java`: la version de partida, una sola clase con un atributo
  tipo. Es la que se reescribe en la parte 2.
- `src/Biblioteca.java`: el catalogo. Se toca solo en el TODO 4.
- `src/Programa.java`: el programa de prueba. No se modifica, salvo comentar y
  descomentar los bloques que indica cada parte.
- `src/Libro.java`, `src/Revista.java`, `src/Prestable.java`,
  `src/Exportador.java`, `src/ExportadorJson.java`: no existen todavia. Se
  escriben en la parte 2.
- `src/Tesis.java` y `src/ExportadorCsv.java`: se escriben en la parte 3.

Para ejecutar, abrir Programa.java y usar el boton Run que aparece sobre el
metodo main.

Las consignas estan en el enunciado de la actividad.
