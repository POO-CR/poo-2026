# Clase 5: herencia

Proyecto Java sin herramientas de construccion. Para abrirlo: en VSCode,
Archivo -> Abrir carpeta, y elegir esta carpeta (la que contiene src y lib).

- `src/Libro.java` y `src/Electronico.java`: completos y funcionando. Se
  modifican en la parte 2.
- `src/Producto.java`: esqueleto con los TODO de la parte 2.
- `src/Alimento.java`: no existe todavia. Se escribe en la parte 3.
- `src/Tienda.java`: el programa que muestra el catalogo. No se modifica,
  salvo para descomentar la parte 3 cuando el enunciado lo indique.

Para ejecutar, abrir Tienda.java y usar el boton Run que aparece sobre el
metodo main. Los archivos compilados van a `bin/`, que no se entrega.

Las consignas estan en el enunciado de la actividad.
