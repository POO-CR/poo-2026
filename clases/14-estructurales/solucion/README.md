# Clase 14: patrones estructurales (solucion)

Proyecto Java sin herramientas de construccion. Para abrirlo: en VSCode,
Archivo -> Abrir carpeta, y elegir esta carpeta (la que contiene src y lib).

- `Escuadra` es Composite: un Combatiente que contiene Combatientes.
- `Equipamiento` es Decorator, con `Espada`, `Escudo` y `Estandarte`.
- `Partida` es Facade sobre `Dado`, `ReglasCombate` y `Bitacora`.
