# Clase 13: patrones creacionales

- `actividad/`: proyecto Java de partida. Es el que hay que abrir y modificar.
  Un juego de oleadas en consola, con sonido, con tres problemas de creacion: el gestor de
  audio se abre tres veces, el heroe tiene un constructor de ocho parametros y
  el nivel decide que enemigo crear con un switch sobre un texto.

La solucion se publica despues de la clase.
