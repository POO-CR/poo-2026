# Clase 11: layout managers

- `actividad/`: proyecto Java de partida. Es el que hay que abrir y modificar.
  Arranca con el conversor de moneda de la clase pasada, con las coordenadas de
  cada componente escritas a mano.
- `ejemplo/`: el ejemplo de la pre clase, en tres proyectos: coordenadas a
  mano, BorderLayout sin paneles, y paneles adentro de paneles. Es para
  mirar, no para modificar.

La solucion se publica despues de la clase.
