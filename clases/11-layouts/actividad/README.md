# Clase 11: layout managers

Proyecto Java sin herramientas de construccion. Para abrirlo: en VSCode,
Archivo -> Abrir carpeta, y elegir esta carpeta (la que contiene src y lib).

Es el conversor de moneda tal como quedo al final de la clase pasada, con tres
botones y las coordenadas de cada componente escritas a mano:

- `src/vista/VistaConversor.java`: la vista. Es donde esta casi todo el
  trabajo de hoy; los TODO estan en el encabezado.
- `src/modelo/Conversor.java`: el modelo. Se amplia en la parte 3.
- `src/controlador/ControladorConversor.java`: el controlador. Se amplia en
  la parte 3.
- `src/Programa.java`: el programa de prueba. No se modifica, salvo comentar y
  descomentar los bloques que indica cada parte.

Para ejecutar, abrir Programa.java y usar el boton Run que aparece sobre el
metodo main. Se abre una ventana; el programa termina al cerrarla.

Las consignas estan en el enunciado de la actividad.
