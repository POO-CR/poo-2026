# Clase 3: encapsulamiento

Proyecto Java sin herramientas de construccion. Para abrirlo: en VSCode,
Archivo -> Abrir carpeta, y elegir esta carpeta (la que contiene src y lib).

- `src/PerfilUsuario.java`: el archivo que hay que modificar.
- `src/PruebaPerfil.java`: el programa que la usa. No se modifica, salvo para
  comentar la parte 1 y descomentar la parte 2 cuando el enunciado lo indique.

Para ejecutar, abrir PruebaPerfil.java y usar el boton Run que aparece sobre
el metodo main. Los archivos compilados van a `bin/`, que no se entrega.

Las consignas estan en el enunciado de la actividad.
