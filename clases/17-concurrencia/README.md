# Clase 17: hilos y recursos compartidos

- `actividad/`: proyecto Java de partida. Es el que hay que abrir y modificar.
  Una arena con ocho jugadores en hilos que comparten el marcador, los
  enemigos, la bitacora y la configuracion, y un intercambio de oro que se
  traba.
- `ejemplos/`: los programas cortos que se ejecutan en la clase, uno por
  concepto. Ver ejemplos/README.md.

La solucion se publica despues de la clase.
