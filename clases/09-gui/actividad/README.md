# Clase 9: interfaz grafica y eventos

Proyecto Java sin herramientas de construccion. Para abrirlo: en VSCode,
Archivo -> Abrir carpeta, y elegir esta carpeta (la que contiene src y lib).

- `src/VentanaConversor.java`: la version de partida, una sola clase que es
  la ventana, atiende el click y hace la cuenta. Es la que se reparte en la
  parte 2, y despues queda sin uso.
- `src/Programa.java`: el programa de prueba. No se modifica, salvo comentar y
  descomentar los bloques y los import que indica cada parte.
- `src/modelo/Conversor.java`, `src/vista/VistaConversor.java` y
  `src/controlador/ControladorConversor.java`: no existen todavia, ni las
  carpetas. Se crean en la parte 2 y se amplian en la parte 3.

Para ejecutar, abrir Programa.java y usar el boton Run que aparece sobre el
metodo main. Se abre una ventana; el programa termina al cerrarla.

Las consignas estan en el enunciado de la actividad.
