# Clase 9: interfaz grafica y eventos

- `actividad/`: proyecto Java de partida. Es el que hay que abrir y modificar.
  Arranca con un conversor de moneda escrito en una sola clase, que es la
  ventana, atiende el click y hace la cuenta.
- `ejemplo/`: el ejemplo de la pre clase completo y ejecutable, en sus dos
  versiones: la ventana que hace de todo y el reparto en modelo, vista y
  controlador. Es para mirar, no para modificar.

La solucion se publica despues de la clase.
