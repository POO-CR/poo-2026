# Clase 1: paradigmas, clases y objetos

Proyecto Java sin herramientas de construccion. Para abrirlo: en VSCode,
Archivo -> Abrir carpeta, y elegir esta carpeta (la que contiene src y lib).

- `src/Estudiante.java`: la plantilla que hay que completar con los atributos
  y metodos que definieron en papel.
- `src/SistemaGestionAlumnos.java`: el programa principal, donde crean los
  dos objetos y los usan.

Para ejecutar, abrir SistemaGestionAlumnos.java y usar el boton Run que
aparece sobre el metodo main. Los archivos compilados van a `bin/`, que no
se entrega.

Las consignas estan en el enunciado de la actividad.
