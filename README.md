# Programación Orientada a Objetos 2026

Código de las actividades de la materia. Universidad Nacional de la Patagonia San Juan Bosco.

Los enunciados, las hojas de pre clase y las presentaciones se publican en el aula
virtual. Acá vive solo el código.

## Cómo se usa

Clonar el repositorio una sola vez, en la carpeta donde trabajen durante el cuatrimestre:

```
git clone https://github.com/POO-CR/poo-2026.git
```

De ahí en adelante, antes de cada clase, traer lo nuevo:

```
git pull
```

Cada actividad es un proyecto Java independiente, listo para abrir en VSCode con
Archivo y después Abrir carpeta. El código va en `src` y los compilados se generan
solos en `bin`, que no se versiona.

## Estructura

```
clases/     una carpeta por clase, con la actividad y, después de la clase, la solución
practicos/  material de las clases prácticas
```

## Dos cosas que conviene saber

Este repositorio es de solo lectura para el curso. Pueden clonarlo y actualizarlo,
pero no subir cambios: `git push` va a fallar por permisos, y está bien que así sea.
El trabajo de cada uno vive en su propia máquina y, cuando corresponda, en el
repositorio de su equipo.

Las soluciones se publican después de cada clase, así que aparecen con un `git pull`
posterior.
